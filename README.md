# OpenAI 生图

在 DeepSeek Harness 的普通对话中生成图片、上传参考图编辑、连续修改结果，并在模型菜单悬停查看能力介绍。

已验证 **DSH Windows 0.2.1-rc.5**。本插件为独立项目，非 DeepSeek 或 OpenAI 官方发行。

## 一行地址安装（国内 Gitee，免 Git）

在 DSH 左侧打开 **插件 → 添加插件 → 安装第三方插件**，把下面这一行粘贴到“包名或地址”中，然后点击安装：

```text
https://gitee.com/un-important/dsh-openai-image/raw/main/local-dsh-openai-image-1.1.0.tgz
```

这是 `.tgz` 安装包直链，不需要安装 Git、Node.js，也不需要登录 Gitee、打开终端或手动解压。DSH 自带安装器会下载并安装插件。

2026-11-04 已验证：未登录 HTTP 下载成功、文件校验一致；隔离环境中 Git 不可用，仍可使用 DSH 自带 pnpm 安装，全部 10 个运行文件与发布包一致。

已安装 Git 且能够访问 GitHub 的用户，也可使用备用安装地址：

```text
github:NL02040616/dsh-openai-image
```

等待安装完成，确认 **OpenAI 生图** 及其组件已启用。看到重启提示时，通过 DSH 顶部 **应用 → 退出** 完整退出后重新打开。

仓库已包含可直接运行的 JavaScript，无需编译，也没有安装或构建脚本。DSH 会下载并管理插件副本，无需手动保存源码目录。

如果之前已经从本地目录或 GitHub 安装过这个插件，请先在 DSH 插件页卸载旧副本，再使用上面的地址安装，并完整退出、重新打开 DSH。插件包标识保留为 `@local/dsh-openai-image`，以避免重复注册。

安装包版本为 **1.1.0**，大小 **11,939 字节**，校验值见 [SHA-256 文件](local-dsh-openai-image-1.1.0.tgz.sha256)。此包不包含任何 API Key。

## 首次配置

1. 打开 DSH **左下角账号菜单 → 设置 → 模型**。
2. 添加或编辑默认的 **OpenAI / openai** 提供商，填写你自己的 OpenAI API Key 并保存。
3. 回到普通对话，在模型菜单中选择 **OpenAI 生图 → GPT Image 2.5 Flare · 生图**。

插件免费，实际生图和改图使用你自己的 OpenAI API 额度。你需要有相应模型权限，并能联网访问 OpenAI 官方 API。分享者的密钥、账号和额度不随插件提供。

## 使用

在普通对话的模型选择器中选择 **OpenAI 生图 → GPT Image 2.5 Flare · 生图**，然后直接发送画面描述。每条消息生成一张图片，结果作为原生图片附件显示并持久保存。完成后切回 GPT/DeepSeek 等聊天模型即可继续普通任务。

上传 PNG、JPEG 或 WebP 图片后，直接描述修改要求，例如“把蓝色圆形改成红色，保留白色背景、位置和尺寸”。支持同一条消息上传多张参考图（最多 16 张），可按上传顺序描述如何组合。

下一条消息直接说“再把背景改成淡黄色”，会使用最近的结果继续编辑；本次新上传的图片优先。要重新创作、不使用旧图时，输入 **“新建图片：……”** 或 **`/new …`**，也可以新开对话。

也可保持当前聊天模型，对它说“请用 OpenAI 生图工具生成……”或上传图片后说“请用 OpenAI 改图工具修改……”。插件注册 `openai_generate_image` 和 `openai_edit_image`，后者自动读取当前会话的图片，无需提供文件路径。

仅发送当前描述和选定的参考图，不发送整个聊天历史或工作区上下文。连续修改默认使用最近一条带图消息中的图片；想回到更早的版本，请重新上传该版本。编辑默认按第一张参考图的横竖方向选择 1536×1024、1024×1536 或方图尺寸，不保证与原图像素尺寸相同。

## 模型悬停说明

将鼠标停在模型选择菜单的名称上，可查看能力特点及上传/续改用法。

| 模型 | 特点 |
| --- | --- |
| GPT Image 2.5 Flare | 速度优先，适合日常创作和快速迭代；支持参考图编辑、主体保留。 |
| GPT Image 2.5 Sunburst | 质量优先，适合复杂画面和精细修改；支持参考图编辑、主体保留。 |
| GPT Image 1 Mini | 经济型，支持生图和改图；仅低输入保真度，官方已标记弃用。 |

说明核对于 2026-11-04：[官方模型选择与编辑指南](https://developers.openai.com/api/docs/guides/image-prompting)、[Mini 模型说明](https://developers.openai.com/api/docs/models/gpt-image-1-mini)、[图片编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)。实际速度与效果随提示词、尺寸及画质变化，修改结果仍需检查。

## 凭据与费用

从 DSH 的凭据服务按名读取现有 `OPENAI_API_KEY`，仅发送到 OpenAI 官方 `/v1/images/generations`（生图）与 `/v1/images/edits`（改图）。参考图通过 DSH 的附件服务读取并以图片数据发送，不把本地文件路径交给 API。不另存 API Key，不读取凭据文件，不向其他站点发送凭据。

默认一张、1024×1024、中画质。实际使用会消耗 OpenAI API 额度。不会自动重试生图请求；会话自动标题只生成本地标题，不调用付费接口。

## 安装和配置

推荐使用上方的 Gitee `.tgz` 直链安装。也可以下载源码 ZIP 并解压，然后在 DSH 插件管理器中填入包含 `package.json` 的目录的完整路径；本地目录安装后不要移动或删除该目录。

安装使用 DSH 原生插件管理机制，不修改程序安装包。插件可在“插件”页面停用或卸载。更新时按 DSH 的提示卸载旧版并重新安装，再完整重启。

Config 字段：`apiKeyEnv`、`defaultModel`、`quality`（low/medium/high）、`size`（1024x1024/1536x1024/1024x1536）、`timeoutMs`。这些字段的默认值见 `cordis.patch.yml`。

本插件不带安装脚本或额外运行时依赖。`peerDependencies` 显式声明需要复用的 DSH 运行时包，这是本地链接安装时解析这些包所必需的。图标为本插件原创 SVG，随代码按 MIT 许可提供。

修改插件 JavaScript 后，正常退出并重新打开 DSH 以加载新模块。首次加载失败的模块也需要重启后重新加载，单独切换启用开关不会清除 Node 的模块缓存。

## 常见问题

- **提示未配置 OPENAI_API_KEY**：按“首次配置”设置默认 `openai` 提供商。这里需要 OpenAI 官方 API Key。
- **能看到模型但调用失败**：模型列表不代表账号有调用权限或剩余额度；以 OpenAI 的实际报错为准。
- **提示无法访问 GitHub**：检查粘贴的是否为上方完整的 Gitee `.tgz` 直链。仓库地址与 `.tgz` 地址是两种安装方式；免 Git 安装应使用以 `.tgz` 结尾的地址。
- **安装失败或版本不兼容**：保留 DSH 插件页的错误信息，检查网络和 DSH 版本。本版未验证其他 DSH 版本，不建议强行绕过版本检查。
- **改图没有保持某些细节**：明确描述只修改什么、哪些内容保持不变；需要回到旧版本时重新上传该图。
- **超时**：插件不会自动重试，请先查看 API 用量再决定是否重新发送。
